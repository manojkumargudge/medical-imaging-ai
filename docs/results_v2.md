# Classifier results (v2)

**For education only, not for clinical use.** These numbers describe agreement with NLP-mined labels on one public dataset. They are not a measure of clinical accuracy.

Generated by `python -m src.models.evaluate --version 2`; do not edit by hand. The version 1 report ([results.md](results.md)) is kept as it was.

- Dataset: NIH ChestX-ray14 (Kaggle nih-chest-xrays/data); labels NLP-mined from radiology reports, not radiologist-verified.
- Model: DenseNet121 (ImageNet weights), checkpoint epoch 3 (highest val mean AUROC over 5 epochs).
- Splits: val (10% of train_val_list.txt patients, seed 42); test (official test_list.txt). The official test split has more findings and more images per patient than val (see eda.md), so val and test results are not directly comparable.
- Thresholds: two sets, both chosen on val only and applied to test unchanged. Set A: highest F1 per label; predict positive when score >= threshold. Set B: highest threshold with val sensitivity >= 0.80; labels with fewer than 30 val positives get no threshold (score only).
- Intervals: 95% percentile bootstrap on test, 1000 resamples of patients (seed 42); all images of a drawn patient are kept together.
